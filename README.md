# BUILDPRIME CONSTRUCTION (University Project)

Simple MERN app for Milestone 2 (Project Progress Tracker + Construction Cost Estimator).

See server/ and client/ folders.

Run:

1. Backend

```bash
cd server
npm install
# create .env (see .env.example)
npm run seed
npm run dev
```

2. Frontend

```bash
cd client
npm install
npm run dev
```
